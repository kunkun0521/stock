## 1. 背景与目标

股票量化预测可以拆成三个数学问题，需要不同的概率模型，不能只靠正态分布或均值：

| 问题 | 要回答什么 | 主要模型 |
| --- | --- | --- |
| 方向 | 上涨、下跌的概率各是多少 | 条件概率/贝叶斯、逻辑回归、马尔可夫链 |
| 幅度 | 期望涨跌幅、分位区间是多少 | 期望值、分位数回归、蒙特卡洛 |
| 风险 | 波动范围多大、大跌概率多高 | GARCH、Student-t、VaR/CVaR、EVT |

**目标**：每个交易日收盘后，为每只符合条件的A股输出多个预测周期的概率化预测；每一次预测都落库，到期后自动结算、复盘，并量化各模型的样本外可靠性。

**设计原则**

- 方向、幅度、风险分别建模，不依赖单一正态假设。
- 多模型输出必须经过统计校准和联合一致性处理，不得简单平均。
- 所有评估为样本外、按时间顺序（walk-forward），严禁未来数据泄漏。
- 如实表达不确定性：模型在样本外没有优势时，系统必须明确标出，而不是输出看似自信的概率。

## 2. 范围

**v1 范围**

- A股日线；预测周期 h ∈ {1, 3, 5, 10} 个交易日（可配置，可增加 20）。
- 输出：上涨/下跌概率、期望涨跌幅、分位区间、波动率、大跌/大涨概率、VaR/CVaR、风险等级、可靠性等级。
- 全链路：特征 → 训练 → 预测 → 落库 → 结算复盘 → 评估 → 简单回测 → 前后端展示。

**不在范围**

- 分钟线、港股、美股（表结构相同，代码保留 `market` 参数和 `DataProvider` 接口，便于后续扩展）。
- 资金流、北向资金、行业、财务数据（`stock_daily` 没有，v1 不使用，预留扩展接口）。
- 实盘下单、自动交易、直接荐股。

## 3. 数据说明

### 3.1 输入表

表 `stock_daily`，主键 `(code, market, trade_date, adjustflag)`。默认只读取 `adjustflag=2`（前复权，可配置）。

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| code, market | 代码（不含前缀）、SH/SZ | 标识股票 |
| open, high, low, close, preclose | 前复权价格（元） | 收益率、技术指标、涨跌停判断 |
| volume, amount | 成交量（股）、成交额（元） | 量能特征 |
| amplitude, pct\_chg, turnover | 百分数（2.5 表示 2.5%） | 入口统一除以 100 转为小数 |
| tradestatus, is\_st | 交易状态（1交易/0停牌）、是否ST | 股票池与停牌处理 |
| pe\_ttm, pb\_mrq, ps\_ttm, pcf\_ncf\_ttm | 估值，可能为空或为负 | 估值分位特征 |

其余字段（chg\_amt、data\_source、created\_at、updated\_at）不使用。

### 3.2 样本窗口与设计影响

窗口 = 全表 `trade_date` 去重后降序取前 `lookback_days=500` 个交易日（可配置）。交易日历直接来自表自身，不依赖外部日历。500 日约两年，且基本处于同一个行情阶段，由此带来这些约束：

| 约束 | 影响 | 设计应对 |
| --- | --- | --- |
| 单股只有约 500 个点 | 复杂模型必然过拟合 | 单股只拟合低参数模型（GARCH(1,1)、3 状态马尔可夫、Student-t）；方向和幅度模型用全市场「股票×日期」合并样本训练 |
| 特征预热约 60 日 | 有效样本约 440 日 | 有效交易日不足 `min_history=250` 的股票不预测 |
| 多日标签相互重叠 | 样本自相关，有效样本更少 | 训练和评估都做 purge（剔除与测试期标签重叠的样本）；显著性检验用按日 block bootstrap |
| 单一行情阶段 | 风格偏差，结论可能不稳 | 特征用横截面标准化和排名；评估报告分月展示 |
| 尾部样本太少 | 单股 99% 分位只有几个点 | EVT 用 GARCH 标准化残差做全市场分组合并拟合 |

### 3.3 表中没有的数据

- 大盘指数：用 `market proxy` 代替，即当日股票池内全部股票收益率的等权平均（可配置为成交额加权），由 `stock_daily` 自己算出。
- 行业、北向资金、主力资金流向：v1 不使用，相关特征和信号不得出现。

## 4. 数据处理规则

### 4.1 股票池（均可配置）

| 规则 | 默认值 |
| --- | --- |
| 代码前缀 | 00、60、30（沪深主板、创业板）；排除 688 科创板、北交所、B股 |
| ST | 排除 asof 日 `is_st=1` 的股票 |
| 样本长度 | 窗口内有效交易日 ≥ 250，自然排除次新股 |
| 停牌 | 最近 60 个交易日内停牌 ≥ 10 天的排除 |
| 当日无数据 | asof 日停牌或无记录则当日不预测 |

被排除的股票数量和原因写入 `prob_run`。

### 4.2 清洗

- 有效行：`close>0`、`high≥low`、`high≥max(open,close)`、`low≤min(open,close)`；不满足的行置为无效并计入 `data_warn_count`。
- 停牌日（`tradestatus=0` 或 `volume=0`）：不参与收益率和技术指标（指标在有效交易日序列上计算），不产生样本；复牌首日的收益跨越停牌区间，不用于 GARCH 拟合；前向窗口 (t, t+h\] 内含停牌日的样本不用于训练（可配置）。
- 估值：`pe_ttm≤0` 或为空视为缺失，不得填 0。
- 缺失特征：缺失率 > 30% 的特征整体剔除；其余用训练集的横截面中位数填充，并保留缺失标志。
- 极端值：特征在横截面按 1%/99% 分位 winsorize，分位点只用训练集统计。

### 4.3 收益率与复权

- 对数收益 `r_t = ln(close_t / close_{t-1})`，在同一次读取的前复权快照内计算。`pct_chg` 只用于涨跌停判断和交叉校验（`abs(r_t − ln(1+pct_chg)) > 0.001` 计入 `data_warn_count`）。
- 前复权价格会随新的除权除息整体改写，所以每次运行必须重新读取完整窗口，禁止把不同次读取的价格拼在一起；结算（settle）也用当次快照计算已实现收益。
- 内部用对数收益，对外输出简单收益率 `exp(R)−1`（小数形式，如 0.023 表示 +2.3%）。

### 4.4 涨跌停

涨跌幅限制表可配置：主板 10%、创业板 20%、ST 5%（ST 规则以交易所最新规定为准，必须配置化，不得写死）。判定涨停：`pct_chg ≥ L − 0.001` 且 `close==high`；跌停同理。用途：(a) 特征 `limit_up_cnt_20`；(b) 蒙特卡洛逐日收益截断；(c) 回测成交约束。

### 4.5 数据完整性检查

`asof_date = max(trade_date)`。若 asof 日有效行数 / 近 20 日日均有效行数 < 0.9，说明当日数据可能没导完，任务按配置报警或中止，避免用半天的数据去预测。

## 5. 预测目标与输出

### 5.1 定义

- `C_t`：前复权收盘价；信号在 t 日收盘后生成，只使用 t 及以前的数据。
- `R_h(t) = ln(C_{t+h} / C_t)`；`Y_h(t) = 1[R_h(t) > 0]`。
- 预测周期 `horizons = [1, 3, 5, 10]`（可配置）。

### 5.2 每只股票、每个周期的输出

| 类别 | 字段 | 说明 |
| --- | --- | --- |
| 方向 | `p_up`、`p_down` | 校准后的上涨/下跌概率，`p_up + p_down = 1` |
| 幅度 | `exp_ret`、`median_ret` | 期望、中位数（简单收益率） |
| 分位 | `q05, q25, q50, q75, q95` | 收益率分位点，必须单调不减 |
| 波动 | `vol_1d_next`、`vol_h` | 次日及 h 日预测波动率（标准差） |
| 风险 | `prob_drop_5`、`prob_drop_10`、`prob_rise_5`、`prob_rise_10` | h 日内收益 ≤ −5%/−10%、≥ +5%/+10% 的概率（阈值可配置） |
| 风险 | `var95`、`var99`、`cvar95` | 以正数损失率表示 |
| 等级 | `risk_level`、`reliability_grade` | 风险等级（低/中/高/极高）、可靠性 A/B/C/D |
| 审计 | 各模型分项概率、`selected_method`、`flags` | 便于复盘与排错 |

## 6. 特征工程

全部特征只用 t 及以前的数据（滚动窗口不得用 `center=True`），每个特征登记在特征注册表（`features.yaml`：名称、公式、回看天数、缺失处理）。

| 类别 | 特征 |
| --- | --- |
| 收益 | `ret_1/3/5/10/20`（对数收益） |
| Z-Score | 当日收益、成交量、换手率、振幅相对过去 20 日均值/标准差的 z 值：`Z=(X−μ)/σ` |
| 趋势 | 收盘价相对 MA5/10/20/60 的乖离；均线多头排列标志；MACD(12,26,9) 的 DIF、DEA、柱值与金叉/死叉标志 |
| 超买超卖 | RSI14；距近 20/60 日最高、最低点的位置 |
| 波动 | ATR14/close；20、60 日已实现波动率；振幅均值 |
| 量能 | `vol_ratio_20`（成交量/20 日均量）、`amount_ratio_20`、换手率 5 日均值 |
| 连续状态 | 连涨/连跌天数；近 20 日涨停、跌停次数 |
| 估值 | `pe_ttm`、`pb_mrq`、`ps_ttm` 在自身窗口内的历史分位（负值/缺失处理见 4.2） |
| 市场联动 | `market_ret_1/5`；个股相对市场的超额收益；60 日滚动相关系数与 beta（`ρ=Cov(X,Y)/(σ_X·σ_Y)`） |
| 横截面 | 上述关键特征在当日全市场的分位排名和 z 值，使模型跨股票、跨行情可比 |

## 7. 模型设计

### 7.1 总体架构与作用范围

```
stock_daily → 清洗 → 特征
   ├─ 方向模型组：M1 条件概率/贝叶斯　M2 逻辑回归　M3 马尔可夫链
   ├─ 波动率模型：M4 GARCH(1,1)-t（失败回退 EWMA）
   ├─ 幅度/分布：M5 期望值　M6 分位数回归　M7 蒙特卡洛（GBM / FHS）
   └─ 风险模型：M8 VaR/CVaR　M9 EVT（P3）
         ↓
   M10 融合（stacking）+ 概率校准 + 联合一致性
         ↓
   落库 → 结算 → 评估 → 回测 → 展示
```

- 单股模型（M3、M4、M7、M8）：只用该股窗口内的数据，参数少。
- 合并模型（M1、M2、M6、M9）：用全市场「股票×日期」样本训练，再对每只股票输出；特征做横截面标准化，使股票之间可比。
- 计算顺序：M4 波动 → M1/M2/M3 → M10 得到 `p_up` → M5 期望 → M6/M7 分布 → M8/M9 风险 → 评级。

### 7.2 方向模型

**M1 条件概率与贝叶斯更新**

```
P(Y_h=1 | S) = (k + m·p0) / (n + m)
```

S 为信号，n 为信号出现次数，k 为其中上涨次数，p0 为训练期基础上涨率，m 为先验强度（`prior_strength=20`，可配置），即 Beta(m·p0, m·(1−p0)) 先验的后验均值。

- 信号注册表（离散化）：MACD 金叉/死叉、RSI14<30、RSI14>70、`vol_ratio_20>2`、均线多头排列、连跌 ≥3 日、连涨 ≥3 日、近 20 日出现涨停、日收益 z>2、日收益 z<−2、`market_ret_1>0`。
- 统计单信号以及不超过 3 个信号的组合；组合样本数 n < `min_n=30` 时回退到父级信号。
- 动态更新：样本按 `0.5^(age/half_life)` 加权（`half_life=60` 个交易日，可配置）后再累计 k、n，使新信息权重更高。
- 多信号合并用朴素贝叶斯的 log-odds 相加：`logit(p) = logit(p0) + Σ(logit(p_i) − logit(p0))`。指标之间往往相关，独立性假设不成立，所以这个输出只作为 M10 的输入之一，不能直接对外发布。
- 结果写入 `prob_signal_stat`，供前端展示「信号命中率」。

**M2 逻辑回归**

```
P(Y_h=1|X) = 1 / (1 + exp(−z)),   z = β0 + β1·X1 + … + βn·Xn
```

- 合并样本训练，每个预测周期一个模型；输入为第 6 章标准化后的特征（含横截面排名）。
- L2 正则，强度 C 用带 purge 的时间序列交叉验证选择；每个交易日等权，避免股票数量多的日子权重过大（可配置）。
- 保存系数，前端展示「因子贡献」。
- 可选挑战者：梯度提升树（如 LightGBM），属 P3；必须同样 walk-forward 评估，只有样本外 Brier 显著优于逻辑回归时才启用。

**M3 马尔可夫链（趋势状态）**

- 状态：涨 U、平 F、跌 D。`r_t > θ_t → U`，`r_t < −θ_t → D`，其余为 F；`θ_t = κ·σ_t`，`κ=0.5`，σ\_t 为 M4 的条件波动（不可用时用 20 日标准差），阈值随波动自适应。
- 转移矩阵：`P_ij = (n_ij + 1) / (Σ_j n_ij + 3)`（拉普拉斯平滑），用单股窗口内全部有效转移计数。
- 当前状态为 s 时，`π_1 = P[s]`，`π_h = π_1 · P^(h−1)`，表示第 h 个交易日当天处于各状态的概率。
- 注意：`π_h(U)` 是「第 h 天当天上涨」的概率，不等于「h 日累计收益 > 0」的概率，所以不得直接当作 `p_up`。它的用途：(a) 作为 M10 的输入特征 `p_markov_h`；(b) 展示趋势延续和反转概率（`P_UU`、`P_DD`、期望连涨天数 `1/(1−P_UU)`）。
- 一阶马尔可夫性检验：对转移计数矩阵做卡方独立性检验，p > 0.10 说明状态几乎没有记忆，转移矩阵每一行与无条件状态分布各占 50% 做收缩（可配置）。

**伯努利与二项分布的位置**

- 伯努利：`Y_h ~ Bernoulli(p_up)`，`p_up` 即最终输出，该分布只负责方向，不描述幅度。
- 二项：`P(X=k) = C(n,k)·p^k·(1−p)^(n−k)`，仅用于 (a) 展示「未来 n 日中上涨 k 天」的概率（假设每天独立同分布，界面必须注明）；(b) 信号或策略胜率的显著性检验（H0：胜率等于基础上涨率）。不用作主预测。

### 7.3 波动率模型（M4：GARCH(1,1)-t）

```
r_t = μ + ε_t,    ε_t = σ_t · z_t,    z_t ~ 标准化 t(ν)（方差为 1）
σ_t² = ω + α·ε_{t−1}² + β·σ_{t−1}²
```

- 约束：ω>0，α≥0，β≥0，α+β<1，2.1<ν≤30。建议用 `arch` 库，收益乘 100 后拟合再还原。
- 拟合窗口：最近 500 个有效收益（至少 250）；每日重拟合（`garch_refit_every` 可配置）。
- 回退：不收敛、参数触边、α+β≥0.999 或样本不足时回退 EWMA：`σ_t² = λ·σ_{t−1}² + (1−λ)·r_{t−1}²`，`λ=0.94`，ν 取全市场合并估计值；记录 `vol_model='EWMA'`。
- h 日方差递推（`σ_bar² = ω/(1−α−β)`，`σ²_{t+1} = ω + α·ε_t² + β·σ_t²`）：

```
E[σ²_{t+k}] = σ_bar² + (α+β)^(k−1) · (σ²_{t+1} − σ_bar²)
σ_h² = Σ_{k=1..h} E[σ²_{t+k}],    vol_h = sqrt(σ_h²)
```

EWMA 回退时 `σ_h² = h·σ²_{t+1}`。

- 输出：`vol_1d_next`、`vol_h`、`vol_pctile_self`（相对自身历史条件波动的分位）、`vol_pctile_mkt`（全市场横截面分位）；`vol_pctile_self>0.8` 标记为高波动阶段。
- 诊断：标准化残差平方的 Ljung-Box 检验、Jarque-Bera 检验，结果存入 `prob_stock_model_state`。
- Student-t 的作用：作为残差分布，ν 越小尾部越厚；评估报告要给出它与正态分布在尾部概率上的差异。

### 7.4 幅度与分布模型

**M5 期望值**

```
E[R_h] = p_up · m_up + (1 − p_up) · m_dn
m_up = k_up · σ_h,    m_dn = k_dn · σ_h
k_up = E[R_h/σ_h | R_h>0],    k_dn = E[R_h/σ_h | R_h≤0]
```

k\_up、k\_dn 用全市场合并训练样本估计，按日等权，估计前先对 `R_h/σ_h` 做 winsorize。该公式把上涨概率和幅度结合起来，避免只看胜率：例如 A 股上涨概率 80%、上涨平均 +1%、下跌平均 −5%，期望为 −0.2%；B 股上涨概率 60%、上涨平均 +5%、下跌平均 −2%，期望为 +2.2%。

**M6 分位数回归**

- 目标变量为标准化收益 `R_h/σ_h`，合并样本，分位 τ ∈ {0.05, 0.25, 0.5, 0.75, 0.95}；特征为第 6 章的精简子集（不超过 20 个：动量、z 值、波动分位、量能、估值分位、相对市场）。
- 实现可选 statsmodels `QuantReg` 或 LightGBM（`objective=quantile`），由编码者按速度和稳定性选择并记录；预测分位 = `σ_h × 预测的标准化分位`；分位出现交叉时做排序修正。
- 损失为 pinball loss：`ρ_τ(u) = u·(τ − 1[u<0])`。
- 输出的是收益率分位点，不代表未来一定落在该区间内。

**M7 蒙特卡洛**

- 基线 GBM：`S_{t+Δ} = S_t · exp[(μ − σ²/2)·Δ + σ·√Δ·Z]`，`Δ = 1/244`（`trading_days_per_year` 可配置），σ 取 `vol_1d_next·√244`。
- 默认 FHS（过滤历史模拟）：用 M4 的标准化残差有放回抽样，逐日按 GARCH 递推更新波动，`r_{t+k} = μ_d + σ_{t+k}·z*_k`，同时体现厚尾和波动聚集；残差池默认为该股自身残差，可配置为混入全市场合并残差。
- 涨跌停截断：每日简单收益 clip 到 `[−L, +L]`（L 见 4.4）。
- 路径数 `n_paths=10000`（可配置为 50000/100000）；随机种子 = `hash(code, asof_date, seed_base)`，保证可复现；用 numpy 向量化并分批处理全市场。
- 统计输出：`P(R_h>0)`、`P(R_h≤−5%)`、`P(R_h≤−10%)`、`P(R_h≥+5%)`、`P(R_h≥+10%)`、分位 {5,25,50,75,95}、均值、VaR/CVaR。
- 漂移 μ\_d：默认由 M10 的一致性处理决定（见 7.6）；基线 GBM 用 M5 的 `E[R_h]` 折算。

### 7.5 风险模型

**M8 VaR / CVaR**

```
VaR_α  = −Q_{1−α}(R_h)                  （R_h 取简单收益，α ∈ {95%, 99%}）
CVaR_α = −E[ R_h | R_h ≤ Q_{1−α} ]
```

分布来自 M7（或 7.7 择优选定的方法）。另外为每只股票计算并展示（只作历史描述，不参与预测）：近 250/500 日最大回撤 `MDD = max_t (Peak_t − Price_t)/Peak_t`，年化 Sharpe `= (E[R] − rf)/σ`（`rf` 默认 2%，可配置），年化波动率。

**M9 极值理论 EVT（P3）**

- 对 M4 标准化残差的下尾（损失 `L = −z`）做 POT：阈值 u 取合并残差的 90% 分位（可配置），超限量 `y = L − u ~ GPD(ξ, β)`，`F(y) = 1 − (1 + ξ·y/β)^(−1/ξ)`，用 `scipy.stats.genpareto` 极大似然拟合（loc=0）。
- 单股超限样本太少，按波动率三分组（低/中/高）做全市场合并拟合；合并后超限样本 < 50 时回退 Student-t。
- 尾部分位与期望损失（n 为总样本数，N\_u 为超限样本数）：

```
VaR_p = u + (β/ξ) · [ ((n/N_u)·(1−p))^(−ξ) − 1 ]
ES_p  = (VaR_p + β − ξ·u) / (1 − ξ)          （ξ<1）
```

- 用途：1 日 99%/99.5% 的 VaR/ES；可选地替换 FHS 残差池中超过阈值的极端尾部（`tail_method='EVT'`）。

**风险等级**：取 `vol_h` 与 `cvar95` 在当日全市场的分位中较大的一个：<30% 低，30–70% 中，70–90% 高，>90% 极高（阈值可配置）。

### 7.6 融合、校准与联合一致性（M10）

1. **Stacking**：元模型为逻辑回归，输入 `logit(p_M1)`、`logit(p_M2)`、`logit(p_markov_h)`、`logit(p_base)`（`p_base` 为正态基线 `P(R_h>0)`，μ 取训练期均值，σ 取 `vol_h`）以及 `vol_pctile_self`；系数可限制为非负。元模型只用 L1 模型的样本外预测来训练（见 8.1）。
2. **校准**：样本外样本 ≥ 5000 时用保序回归（isotonic），否则用 Platt（sigmoid）；校准器同样按时间顺序拟合，并用最近一个样本外块评估 ECE。
3. **截断**：`p_up ∈ [0.05, 0.95]`（可配置）。
4. **联合一致性**：`consistency_mode=direction`（默认）时，M7 的漂移 μ\_d 用二分法求根，使模拟的 `P(R_h>0)` 等于最终 `p_up`（所有候选漂移共用同一批随机数，保证单调平滑），分布均值作为 `exp_ret`。同时保留 M5 的 `exp_ret_cond` 作交叉检验，两者符号相反时记 `flags='EXP_SIGN_MISMATCH'`。`consistency_mode=expectation` 时漂移取自 M5。
5. **禁止**：对各模型概率做未经校准的简单平均或加权平均；把相关指标的概率直接相乘。

### 7.7 方法择优

同一个输出有多个候选方法时，对每个预测周期用样本外指标择优，选中的方法写入 `selected_method`，每 20 个交易日重评一次：

| 输出 | 候选方法 | 择优指标 |
| --- | --- | --- |
| `p_up` | M10 融合、M1、M2 | 样本外 Brier / LogLoss |
| `exp_ret` | M5 条件期望、分布均值（7.6） | MAE、横截面 Rank IC |
| 分位数 | location-scale t、FHS、M6 分位数回归 | pinball loss、覆盖率 |
| 波动率 | GARCH-t、EWMA | QLIKE |
| VaR/CVaR | FHS、EVT、Student-t | Kupiec 检验通过率 |

location-scale t：`R_h = μ_h + σ_h·z`，`z ~ 标准化 t(ν)`，分位数有解析解。

## 8. 训练与评估

### 8.1 Walk-forward 方案

默认按窗口内交易日序号（1…500）划分，均可配置：

| 阶段 | 区间 | 说明 |
| --- | --- | --- |
| 特征预热 | 第 1–60 日 | 不产生样本 |
| L1 初始训练 | 第 61–240 日 | 合并样本约「180 日 × 全市场股票」 |
| 样本外评估 | 第 241 日至 500−h | 每 20 日一个测试块；训练集 = 此前全部有效样本，并剔除标签与测试块重叠的最后 h 日（purge） |
| L2 融合与校准 | 随样本外块滚动 | 用此前各块的 L1 样本外预测训练元模型和校准器，再预测当前块 |
| 实盘预测 LIVE | asof = 最新交易日 | L1 用全部已有标签的样本重训（标签截止到 asof−h），L2 用累计样本外预测 |

- L1 指 M1、M2、M6 等合并模型；M3、M4 等单股模型在每个测试日只用该日及以前的数据拟合，天然没有泄漏。为控制耗时，walk-forward 中 GARCH 可每 5 日重拟合一次，其间固定参数、只更新波动递推（`backtest_garch_refit_every=5`，可配置）。
- 特征标准化统计量、winsorize 分位点、缺失填充值、先验 p0 都只能来自训练期，严禁使用测试日之后的任何信息。
- 样本外预测以 `pred_type='OOS'` 落库，实盘预测为 `'LIVE'`。

### 8.2 评估指标

| 对象 | 指标 | 说明 |
| --- | --- | --- |
| 方向 | Brier、LogLoss、AUC | AUC 按交易日在横截面计算后取均值 |
| 方向 | 校准曲线、ECE | 10 等分箱，对比预测概率与实际上涨频率 |
| 方向 | Brier Skill Score | `BSS = 1 − Brier_model / Brier_base`，base 为训练期基础上涨率 |
| 幅度 | MAE、横截面 Rank IC | 每日 Spearman（预测期望, 实现收益）的均值与 `IC_IR = mean/std`；五分位分层的平均实现收益 |
| 分位/区间 | pinball loss、覆盖率 | 实现收益低于 q05 的比例应接近 5%，低于 q95 的比例接近 95%，q05–q95 区间覆盖率接近 90% |
| 波动 | QLIKE、相关与偏差 | 已实现波动 = h 日内 `sqrt(Σ r²)` |
| 风险 | VaR 突破率、Kupiec 检验 | 突破率应接近 1−α；Christoffersen 独立性检验可选 |
| 显著性 | block bootstrap 置信区间 | 以交易日为单位，block 长度 = h（标签重叠） |

每项指标分别按全市场、分月、波动率分组、预测周期输出，写入 `prob_eval_metric`。

### 8.3 基准

- B0：训练期基础上涨率（常数概率）。
- B1：正态分布（样本均值、`vol_h`）。
- B2：随机游走（`p=0.5`，均值 0）。

所有指标必须同时给出相对基准的差异。

### 8.4 可靠性评级

- 周期层（每个 horizon）：`BSS>0` 且 bootstrap 95% 区间下界 >0 → 基础 A；`BSS>0` 但区间包含 0 → 基础 B；`BSS≤0` → 基础 C，并在界面标明「无样本外预测优势」。
- 个股层降级因素（每命中一项降一档，最低 D，阈值可配置）：vol\_model 回退为 EWMA；有效样本 < 300；近 120 日 VaR 突破率超出 Kupiec 95% 接受区间；`flags` 含 `EXP_SIGN_MISMATCH`；近 20 日有停牌或涨停 ≥ 3 次。

### 8.5 简单回测（检验预测是否可交易）

- 选股：每日在股票池中按 `p_up`（或 `exp_ret/vol_h`）取前 N 只（`top_n=20`，可配置），要求 `reliability_grade` 不低于 B（可配置）。
- 成交：t+1 日开盘买入，t+1+h 日收盘卖出（满足 T+1，也比标签口径更保守）；买入日开盘即一字涨停（`open ≥ preclose×(1+L)−ε` 且 `high==low`）视为买不到；卖出日跌停则顺延到下一个可卖日。
- 成本（可配置）：佣金 0.025% 双边，印花税 0.05% 仅卖出，滑点 0.1% 单边。
- 组合：等权；每日新开仓、持仓相互重叠（每笔占 1/h 的资金）。
- 输出：净值、年化收益、年化波动、Sharpe、最大回撤、胜率（用二项检验判断是否显著高于 50%）、换手、相对全市场等权基准的超额。
- 注意：回测只用于检验样本外预测是否可交易；样本期仅约两年且行情单一，结果页必须标注这一点。

### 10.1 任务与命令（引擎侧）

| 任务 | 命令示例 | 内容 |

| 训练 | `engine train` | 训练并保存合并模型（M1、M2、M6、k\_up/k\_dn） |

| 日常 | `engine daily` | prepare → 按间隔 train（`retrain_every=20`）→ predict → settle → 增量 evaluate |

### 10.2 工程规则

- 幂等：同一主键重跑覆盖（upsert）。
- 容错：单只股票失败不中断整体，记录原因；失败率超过 5%（可配置）整体告警。
- 并行：单股任务按股票多进程并行（`n_jobs` 可配置），合并模型用向量化计算。
- 可复现：固定随机种子；配置和代码版本写入 `prob_run`。
- 性能目标：全市场（约 4000–5000 只）单日 LIVE 预测在普通桌面机上 ≤ 30 分钟（`n_paths=10000`、4 个周期）；全量 walk-forward 可以更久，但必须支持按 asof\_date 断点续跑。

**通用验收**

- 第 14 章单元测试全部通过。
- 无未来数据泄漏：把 asof 之后的数据随机篡改，该 asof 的预测结果必须完全不变。
- 所有可配置参数都在配置文件中；每条预测都能通过 `run_id`、`model_version` 追溯到配置。
- 交付 README、`docs/decisions.md` 和一份模型说明。

**关于预测效果的验收口径**：短周期涨跌方向的真实预测优势通常很小，所以不以「胜率」或「AUC 达到某个高值」作为验收标准，而是看：概率是否校准良好、是否不劣于基准、分位和 VaR 覆盖率是否合格、可靠性是否如实标注。样本外没有优势的周期，必须标为 C 或 D 级。

## 15. 风险与免责声明

**已知局限**

- 样本只有约两年且行情阶段单一，模型可能对其他行情不适用；任何统计结论都带有较大不确定性。
- 历史统计得到的概率不能保证未来；市场结构变化、政策、突发事件都会使模型失效。
- 前复权价格会被后续除权除息改写、停牌和涨跌停规则调整，都可能影响结果；相关规则必须配置化。
- 表内没有行业、资金流、指数和股票名称，v1 只能用 `stock_daily` 自身衍生的信息。
- 多个指标之间有相关性，只要用条件概率或朴素贝叶斯，就必须靠 stacking 和校准来修正，而不能直接相乘。
