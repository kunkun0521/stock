## 1. 背景与目标

- 对股票池内每只股票，每个交易日给出未来 1、3、5、10、15 个交易日的 看涨 / 看跌 / 观望 预测，并附概率与置信度。
- 用遗传算法（GA）持续进化“预测个体”（因子权重 + 特征选择 + 观望区间），按适应度淘汰差的个体，保留并集成好的个体。
- 淘汰要有记录：（a）模型个体的淘汰；（b）股票的淘汰（长期难以预测或不具备可交易性），都可追溯、可复活。
- 每条预测到期后自动回填真实涨跌，提供可视化看板，方便回顾“哪些预测对了、哪些错了、为什么错”。
- 现实预期：A 股日线方向预测在扣除噪声后，样本外平衡准确率达到 52%–58% 已属有效。系统目标是“稳定略优于随机 + 概率经过校准 + 全程可复盘”，不承诺收益。

## 2. 范围与约束

- 股票池：默认 code 以 00、60、30 开头（market 为 SH 或 SZ），排除 688、北交所、B 股；配置项 `universe_prefixes`。
- 预测周期 H = {1, 3, 5, 10, 15}，单位为该股票的交易日；配置项 `horizons`。每个周期独立维护种群、冠军与指标。
- 基准日 t：t 日收盘数据入库后产生预测，只使用 ≤ t 的数据。tradestatus = 0（停牌）的日子不产生基准日。
- 到期日：该股票在 stock\_daily 中 t 之后第 h 个 tradestatus = 1 的交易日。未来交易日不可预知，所以到期日在回填时才写入，在此之前预测状态为 PENDING。若 t 之后 30 个自然日仍凑不满 h 个交易日，状态置为 VOID。
- 防未来函数（必须）：（1）特征 f(t) 只用 ≤ t 的数据；（2）训练段与验证段之间留 h 个交易日隔离带（purge）；（3）Hold-out 段在进化全程不可见；（4）回填收益时一律重新从 stock\_daily 读取 t 与到期日的 close 计算，不使用预测时保存的 base\_close（前复权价格在新除权日后会整体重算，base\_close 仅作展示）。
- 数据量：GA 一次运行至少需要 T\_min = 150 个有标签交易日（配置项 `min_labeled_days`），建议补足 500 个交易日以上历史。不足时按 6.4 节降级，仍不足则运行失败并写明原因。
- 涨跌停：标签按收盘价计算，不考虑能否成交；预测时记录 t 日是否涨跌停（`limit_flag`），看板提示“追涨风险”。涨跌停幅度：30 开头 ±20%，其余主板 ±10%，ST ±5%（按 is\_st）。

## 3. 总体架构与数据流

1. 特征：stock\_daily + stock\_score\_daily → `stock_feature_daily`（个股特征）与 `ga_market_daily`（市场环境）。
2. 标签：按第 5 节计算 ret\_h 与噪声阈值，仅在内存使用，不落库。
3. 进化（EvolveJob）：每个周期独立运行 GA（第 6 节），产出名人堂与候选冠军集。
4. 准入与影子运行：候选通过 Hold-out 门槛后影子运行若干交易日，再自动晋升为冠军集（`ga_champion_set`）。
5. 预测（PredictJob）：每日收盘后，用冠军集对池内每只股票、每个周期集成打分，写入 `ga_prediction`（PENDING）。
6. 回填（VerifyJob）：到期的预测回填真实收益与对错（VERIFIED / VOID）。
7. 评估与淘汰（MetricJob / PoolJob）：汇总指标、淘汰与复活股票、检查冠军是否衰减。
8. 看板（第 11 节）：读取 `ga_metric_daily`、`ga_prediction`、`ga_stock_pool` 等展示与复盘。

### 4.2 预处理规则（必须）

1. 个股特征先在每个交易日的股票池截面内做 1% / 99% 分位缩尾（winsorize），再做 z-score（均值 0、标准差 1）。市场环境特征用自身滚动 252 日时间序列 z-score。
2. 缺失处理：某日某特征缺失率超过 30% 则该日该特征整体置 0 并记录告警；其余缺失在 z-score 之后填 0。
3. 倒数类估值特征（ep、bp、sp、cfp）先判断符号再取倒数，之后同样缩尾标准化。
4. 可选：训练前对相关系数绝对值大于 0.95 的特征对只保留 IC 更高者（配置项 `dedup_corr`，默认 0）；默认依靠 GA 自带的特征开关做选择。
5. `stock_feature_daily` 存原始（未标准化）特征值；标准化在内存按日截面完成，保证口径可重算。

## 5. 标签与评价口径

- 未来收益：`ret_h(t) = C_(t+h) / C_t − 1`，C\_(t+h) 为到期日的收盘价。
- 噪声阈值：`θ_h(t) = max(floor_h, 0.25 × vol_20(t) × √h)`；floor 默认 1 日 0.2%、3 日 0.4%、5 日 0.5%、10 日 0.8%、15 日 1.0%（配置项）。
- 训练与适应度标签：ret\_h > 0 记 y = 1，否则 y = 0；`abs(ret_h) < θ_h` 的样本视为噪声，不参与训练与适应度计算（但参与复盘统计）。
- 预测输出：`p_up = sigmoid(s)`，其中 s 为第 6.2 节的打分。p\_up ≥ 0.5 + δ 输出 涨（+1）；p\_up ≤ 0.5 − δ 输出 跌（−1）；其余输出 观望（0）。
- 看板默认的“预测正确”口径：预测涨 ⇔ ret\_h > 0；预测跌 ⇔ ret\_h < 0；观望不计入命中率，只计入覆盖率。另存 `is_effective`（方向正确且 abs(ret\_h) ≥ θ\_h）作为严格口径，看板可切换。
- 可选标签模式 `label_mode = EXCESS`：ret\_h 减去同日股票池等权平均 ret\_h，用于剔除大盘 beta；默认 ABSOLUTE。
- 类别不平衡（熊市中下跌样本更多）：适应度使用平衡准确率 BalAcc = (TPR + TNR) / 2，而不是普通准确率。

## 6. 遗传算法设计

### 6.1 个体编码（每个周期独立种群）

| 基因 | 类型与范围 | 含义 |
| --- | --- | --- |
| w\[0..N-1\] | 实数，\[-3, 3\] | 第 j 个特征的权重，符号即方向（正 = 该因子越大越看涨） |
| m\[0..N-1\] | 位，0 或 1 | 特征开关（特征选择）。初始化时每位以 0.3 概率为 1，且至少 3 位为 1 |
| b | 实数，\[-1, 1\] | 偏置，吸收大盘整体涨跌倾向 |
| delta | 实数，\[0, 0.15\] | 观望区半宽 |

持久化为 JSON（键 w、m、b、delta），特征顺序以 `ga_run.feature_set_json` 为准。

### 6.2 个体打分公式

`s = b + (Σ_j m_j × w_j × z_j) / √max(1, Σ_j m_j)`，`p = 1 / (1 + e^(−s))`，z\_j 为标准化后的特征值。

### 6.3 适应度函数

在一个数据段内（已剔除噪声样本）先计算：

- BalAcc：只在非观望预测上计算 (TPR + TNR) / 2。
- IC：逐个交易日在截面上计算 Spearman(s\_i, ret\_h,i)，再对日期取均值。
- Brier = mean((p − y)²)。
- S（稳定性）：段内每 10 个交易日为一块，BalAcc > 0.5 的块占比。
- cov：非观望样本占比。

归一化：A = clip((BalAcc − 0.5) / 0.15, 0, 1)；B = clip(IC / 0.06, 0, 1)；R = clip((0.25 − Brier) / 0.02, 0, 1)。

段内得分：`F_seg = (0.40A + 0.25B + 0.20S + 0.15R) × min(1, cov / cov_target)`，cov\_target = 0.30；若 cov < cov\_min（0.10），F\_seg = 0。

最终适应度：`F = F_va − 0.5 × max(0, F_tr − F_va) − 0.05 × (Σm / N)`。其中 F\_tr、F\_va 分别为各折训练段、验证段 F\_seg 的均值；第二项惩罚过拟合，第三项惩罚模型复杂度。选择压力全部作用在 F 上。以上权重与系数均为配置项。

### 6.4 数据切分与滚动验证（walk-forward）

- 令 D 为有标签的交易日序列（即 t + h ≤ 最新交易日）。最近 `holdout_days`（默认 20）个有标签日作为 Hold-out，进化全程不可见，只用于冠军准入。
- 其余日期做 K = 3 折滚动：训练段 \[a\_k, b\_k\]，隔离带 h 个交易日，验证段 \[b\_k + h + 1, c\_k\]。默认训练段 120 日、验证段 30 日、折间步长 30 日。
- 数据不足时依次降级：K 从 3 降到 2 再到 1，训练段缩短到 60 日，并在 `ga_run` 记录告警；有标签日少于 T\_min 时拒绝运行，写 status = FAILED 与 error\_msg。
- 样本采样：每个交易日从股票池随机取 `sample_per_day`（默认 600）只，运行级固定随机种子保证可复现。样本矩阵一次性加载到内存，所有个体共享。

### 6.5 遗传算子与默认参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| pop\_size | 200 | 种群规模 |
| max\_gen | 60 | 最大代数 |
| patience | 10 | 连续 10 代最优 F 提升小于 1e-4 则早停 |
| 选择 | 锦标赛 k = 3 | 每次随机取 3 个，F 最高者入选 |
| elite\_ratio | 5% | 精英直接进入下一代 |
| 交叉 pc | 0.8 | w、b、delta 用 BLX-α（α = 0.3）并裁剪到范围内；m 用均匀交叉 |
| 变异 | pm\_w = 0.15，pm\_m = 0.03 | 实数基因加高斯噪声 N(0, σ\_g)，σ\_g = 0.5 × (1 − g / max\_gen) + 0.05；m 位翻转后若 1 的个数少于 3 则随机补足 |
| immigrant\_ratio | 10% | 每代注入随机新个体，保持多样性 |
| 多样性 | 阈值 0.05 | diversity = 种群 w（按 m 掩码）的平均成对欧氏距离 / √N；低于阈值时 pm\_w、pm\_m 暂时翻倍，移民比例升到 20% |
| 初始种群 | 50 / 30 / 20 | 50% 随机；30% 因子先验（momentum\_score、trend\_score 权重为正，risk\_score 为负，加噪声）；20% 为上一次冠军的变异体（热启动） |

### 6.6 模型层淘汰（必须记录）

1. 代内淘汰：每代按 F 排序，末位 `cull_ratio`（默认 30%）被淘汰，由交叉与变异后代补位；淘汰数写入 `ga_generation_stat.culled_count`。
2. 绝对淘汰：F < 0.05，或 F\_tr − F\_va > 0.3（严重过拟合），或验证段 BalAcc < 0.5 的个体，不得进入名人堂或候选集。
3. 持久化范围：只持久化名人堂（每次运行 F 最高的 20 个，status = HOF）、候选、冠军与退役个体，不保存每代全部个体。
4. 冠军退役：冠军个体在实盘（含影子）样本上，近 60 个交易日 BalAcc < 0.5 且样本数 ≥ 3000，则 status = RETIRED，retire\_reason = LIVE\_DECAY，并立即触发该周期重新进化。

### 6.7 冠军产生、准入与集成

1. EvolveJob 结束后，从名人堂取前 K = 5 个个体组成候选集（在验证样本上打分相关系数大于 0.9 的两个个体只保留 F 高者），status = CANDIDATE。
2. Hold-out 门槛：候选集集成后在 Hold-out 上 BalAcc ≥ 0.52，且不低于当前冠军集在同一 Hold-out 上的 BalAcc；首次没有冠军时只需 ≥ 0.51。不通过则丢弃并记录原因。
3. 通过门槛后影子运行 `shadow_days`（默认 5）个交易日：候选集同样产出预测，`model_role = SHADOW`，不进入主榜。期满后若影子 BalAcc ≥ 现任冠军 − 0.01，则自动晋升：写入 `ga_champion_set` 新版本，旧版本 is\_current = 0 并写 effective\_to；冠军个体 status = CHAMPION，被替换者 status = RETIRED，retire\_reason = REPLACED。
4. 集成打分：冠军集 K 个个体各自得到 p\_k，集成概率 `p̄ = Σ w_k × p_k`，`w_k = softmax(F_k / 0.1)`；集成观望区 δ\_ens = Σ w\_k × δ\_k。

### 6.8 历史回放（Replay，必须）

新系统上线时没有历史预测，无法复盘。回放功能：给定 replay\_from、replay\_to 与 replay\_step（默认 10 个交易日），对每个断点 d：仅用 ≤ d 的数据运行 GA（可用较小参数 pop\_size = 100、max\_gen = 30）→ 取冠军集 → 对 (d, d + step\] 内每个交易日生成预测，写入 `ga_prediction`（is\_replay = 1），到期后同样回填。回放必须严格遵守防未来函数，因此得到的是真正的样本外历史预测。支持断点续跑（`ga_run` 已完成的断点跳过）。看板可筛选“仅实盘 / 含回放”。

## 7. 股票淘汰机制（必须记录）

“淘汰”指把股票移出主预测榜、进入淘汰池，不删除任何数据。每次状态变化都要写事件日志，可追溯、可复活。

| 原因码 | 触发条件（默认，均可配置） | 评估频率 | 复活条件 |
| --- | --- | --- | --- |
| POOR\_PREDICTABILITY | 近 60 个基准日内，该股已验证的非观望预测（5 个周期合并，仅实盘冠军预测）样本数 ≥ 40 且命中率 < 0.48 | 每周 | 淘汰满 20 个交易日冷却后，影子预测近 20 个基准日样本 ≥ 20 且命中率 ≥ 0.52 |
| SUSPENDED | 近 20 个交易日 tradestatus = 0 的占比 > 30% | 每日 | 占比 < 10% |
| ST | is\_st = 1（配置项 exclude\_st，默认 1） | 每日 | is\_st = 0 |
| NEW\_LISTING | stock\_daily 中该股有效交易日 < 120 | 每日 | 有效交易日 ≥ 120 |
| LOW\_LIQUIDITY | 近 20 日平均成交额 < 2000 万元 | 每日 | 近 20 日平均成交额 ≥ 3000 万元（迟滞防抖） |
| EXTREME\_VOL | 当日 vol\_20 的截面分位 > 99% | 每周 | 截面分位 < 95% |
| DATA\_MISSING | 近 5 个交易日 close、volume、amount 缺失率 > 20% | 每日 | 缺失率为 0 |
| MANUAL | 看板手动淘汰 | 无 | 手动复活 |

处理流程：

1. PoolJob 评估后，状态变化时更新 `ga_stock_pool`，同时写一条 `ga_stock_elimination_log`（event\_type 为 ELIMINATE 或 RESTORE），包含原因码、原因说明与指标快照 metric\_json（命中率、样本数、窗口、阈值）。
2. 被淘汰股票不进入主预测榜与主指标统计（`ga_prediction.in_pool = 0`）。原因为 POOR\_PREDICTABILITY、EXTREME\_VOL、LOW\_LIQUIDITY 时，继续生成影子预测（in\_pool = 0）用于复活判断；其余原因不再生成预测。
3. 白名单：看板可把股票设为 WHITELIST，自动规则不再淘汰它（数据缺失与停牌导致无法预测的除外）。
4. 防抖：同一只股票 20 个交易日内最多自动淘汰一次、复活一次。
5. 每次 PoolJob 结束输出汇总日志：本次淘汰 n 只、复活 m 只、各原因分布。

## 9. 预测、回填与指标汇总

### 9.1 PredictJob（每个交易日收盘数据入库并完成特征计算后）

1. 取最新交易日 t（stock\_daily 中最大 trade\_date，且 stock\_feature\_daily 已生成）。
2. 对每个周期 h：读取当前冠军集；对池内（及影子预测范围内）valid\_flag = 1 的每只股票，标准化特征 → 各冠军个体得分 s\_k → 概率 p\_k → 集成 `p̄ = Σ w_k × p_k`。
3. 校准：`p_cal = sigmoid(a × logit(p̄) + b)`，a、b 取自 ga\_config 的 calib\_a、calib\_b（默认 1 与 0）。每周在 Hold-out 与最近 60 个基准日已验证样本上，对 logit(p̄) 做一维逻辑回归重新拟合；样本少于 500 时保持默认。
4. 方向与置信度：p\_cal ≥ 0.5 + δ\_ens 为看涨；p\_cal ≤ 0.5 − δ\_ens 为看跌；其余为观望。`confidence = abs(p_cal − 0.5) × 2`。
5. 可解释性：特征 j 的贡献 `c_j = Σ_k w_k × m_kj × w_kj × z_j / √(Σ_j m_kj)`，保存绝对值最大的正负各 5 个到 explain\_json。
6. 同时写入 limit\_flag、is\_st、vol\_20、amount\_ma\_20、pe\_ttm、regime 快照，供失败归因使用。
7. 候选集（影子运行期间）以 model\_role = SHADOW 同样预测一份。
8. 幂等：同一唯一键已存在且 status = PENDING 时覆盖，已验证的不得改写。
9. 结束后输出日志：各周期预测条数、看涨 / 看跌 / 观望占比。

### 9.2 VerifyJob（PredictJob 之后每日执行）

1. 选取 status = PENDING 的预测。对每条，在 stock\_daily 中找 t 之后第 h 个 tradestatus = 1 的交易日作为 target\_date；尚不足 h 个则保持 PENDING；t 之后超过 30 个自然日仍不足则置 VOID。
2. 重新从 stock\_daily 读取 t 日与 target\_date 的 close：`actual_return = close_target / close_t − 1`。actual\_direction：收益大于 0 为 1，小于 0 为 −1，等于 0 为 0。
3. is\_correct：pred\_direction = 0 时为空；否则与 actual\_direction 相同记 1，其余记 0（收益恰为 0 记 0）。is\_effective = is\_correct 为 1 且 abs(actual\_return) ≥ θ\_h(t)，θ 用预测快照里的 vol\_20 重算。
4. 写 status = VERIFIED 与 verified\_at。批量更新（每批 5000 条），可重复执行且结果一致。
5. 完成后触发 MetricJob 与 PoolJob（每日轻量规则）。

### 9.3 MetricJob

- 汇总 `ga_metric_daily`：按统计日、周期、范围（ALL / 板块 / 市场状态）、窗口（当日到期、近 20、近 60 个基准日）与 is\_replay 分别计算：n\_pred、n\_verified、n\_correct、hit\_rate = 命中数 / 已验证非观望数、up\_hit\_rate、down\_hit\_rate、coverage、ic、avg\_ret\_up、avg\_ret\_down、spread。只统计 in\_pool = 1 且 model\_role = CHAMPION 的预测。
- 冠军个体实盘表现：对冠军集每个个体，在最近 60 个已到期基准日上，用 stock\_feature\_daily 与真实收益重算 BalAcc、IC、Brier、coverage，写入 `ga_individual_perf`，供 6.6 的冠军退役判断。
- 整体告警：任一周期近 20 个基准日命中率低于 0.50 并持续 5 个交易日，则看板顶部显示红色告警，并自动触发该周期 EvolveJob。

## 10. 新增增强功能（基于业内常用方法）

以下功能参考量化研究中的常见做法（Alphalens 因子分析、Platt 校准、Walk-forward 验证等），均基于 stock\_daily 与 stock\_score\_daily 的现有数据实现。

### 10.1 市场状态识别（Market Regime）

- 目的：同一套因子在上升、震荡、下跌环境里的表现差异很大，需要分环境评估。
- 实现：用 `ga_market_daily.mkt_index`（池内等权净值）。regime = 1（上升）：指数高于 MA60，且今日 MA20 高于 5 日前的 MA20；regime = 3（下跌）：指数低于 MA60，且今日 MA20 低于 5 日前的 MA20；其余为 2（震荡）。可选升级为 3 状态 HMM（输入 mkt\_ret\_1 与 mkt\_vol\_20）。
- 可选 `regime_specific = 1`：每个周期按 regime 训练 3 套冠军集，预测时按当日 regime 选用；某个 regime 的样本少于 3000 时回退到通用冠军。
- 使用方法：在“总览”和“错误分析”中按 regime 切分命中率。若下跌状态命中率明显偏低，可提高 delta 的下限（让模型在该状态多观望）或开启 regime\_specific。

### 10.2 因子体检与衰减预警

- 目的：知道哪些因子在起作用，哪些已经失效。
- 实现：每日对每个特征、每个周期计算截面 Rank IC（特征 z 值与 ret\_h 的 Spearman 相关），汇总 ic\_20、ic\_60、icir\_60，写入 `ga_factor_ic_daily`。当 ic\_20 与 ic\_60 符号相反且 abs(ic\_60) ≥ 0.02 时 decay\_flag = 1。
- 可选联动：decay\_flag = 1 的特征，在新一轮进化的初始种群中 m 位置 1 的概率降为 0.1。
- 使用方法：打开“因子体检”页，热力图（特征 × 周期，颜色表示 ic\_60）中带红框的为衰减预警。长期 IC 接近 0 的特征可写入 ga\_config 的 `excluded_features` 排除。

### 10.3 概率校准与可靠性曲线

- 目的：让“70% 看涨”真的接近 70% 的上涨比例。
- 实现：校准见 9.1 的 Platt 校准。可靠性曲线把 prob\_up 按 0.05 等宽分桶，比较桶内平均预测概率与实际上涨比例；ECE = Σ (n\_桶 / n) × abs(平均预测概率 − 实际上涨比例)。
- 使用方法：在“错误分析”的可靠性曲线页，曲线越贴近对角线越可信；ECE 大于 0.05 时页面提示“建议重新校准”（可在配置页手动触发校准重拟）。

### 10.4 分位分层回测（信号单调性检验）

- 目的：验证“概率越高，后续收益越高”。
- 实现：每个基准日把池内股票按 prob\_up 从低到高分 5 组（Q1 到 Q5），统计各组未来 h 日平均收益与上涨比例；多空价差 = Q5 − Q1；单调性 = Spearman(组号, 组平均收益)；再对所有基准日聚合。
- 使用方法：“错误分析”页的分层回测图（柱状为各组平均收益，折线为累计多空价差）。价差长期为正且单调性高于 0.8 说明信号有效；否则不建议参考选股榜。

### 10.5 多周期共振与每日选股榜

- 实现：consensus = 5 个周期 pred\_direction 之和（范围 −5 到 +5）；avg\_conf = 非观望周期置信度的均值。看涨榜按 consensus 降序、avg\_conf 降序；看跌榜相反。已淘汰股票不入榜；看涨且涨停（limit\_flag = 1）的打“追高风险”标签。
- 使用方法：每日打开“选股榜”，consensus ≥ 4 视为强共振。每行展示 5 个周期的方向与概率、该股近 60 日命中率，点击进入个股详情。

### 10.6 失败归因（错误分析）

- 目的：知道“错在哪类股票、哪种环境”，而不只看总体命中率。
- 实现：对已验证预测按维度分桶统计命中率与样本数：vol\_20（5 分位）、amount\_ma\_20（5 分位）、pe\_ttm（亏损 / 小于 20 / 20 到 50 / 大于 50）、板块（00、60、30）、regime、概率分桶、limit\_flag。另提供混淆矩阵（预测涨跌 × 实际涨跌）和“高置信度错误 Top 20”（confidence ≥ 0.3 且 is\_correct = 0，按 abs(actual\_return) 降序）。
- 使用方法：某个桶命中率明显低于 0.5 且样本 ≥ 200 时，可在配置里加过滤条件（如提高最低成交额、排除亏损股），或在第 7 节新增淘汰规则；逐条打开高置信错误的个股详情，看当时 explain\_json，判断是哪些因子把预测带偏。

### 10.7 影子运行与过拟合监控

- 实现：影子运行规则见 6.7；同时统计每个冠军版本从训练段 → 验证段 → Hold-out → 实盘的 BalAcc 变化，生成衰减曲线。
- 使用方法：在“进化监控”页看衰减曲线。若 Hold-out 与实盘远低于验证段，说明过拟合，应加大过拟合惩罚系数或增大 holdout\_days。

### 10.8 模型版本管理与回滚

- 实现：`ga_champion_set` 保留全部历史版本；回滚时新写一版 is\_current = 1 的记录，旧版置 0，不删除历史，保证任意时刻只有一个当前版本。
- 使用方法：在“进化监控”页选两个版本对比 Hold-out 与实盘命中率；表现劣化时点“回滚”。

### 10.9 可交易性与风险标记

- 实现：每条预测带 limit\_flag、is\_st 与流动性分档（amount\_ma\_20 低于 5000 万元为低流动性）。看板对看涨且涨停的标的显示“追高风险 / 可能买不到”，对看跌且跌停的显示“可能卖不出”。仅作提示，不改变预测。
- 使用方法：在“预测复盘”和“选股榜”中直接看到标记，可按标记筛选。

### 10.10 个股可预测性排行

- 实现：用 `ga_stock_pool.hit_rate_60` 展示最可预测 Top 50 与最不可预测 Top 50。
- 使用方法：在“淘汰管理”页查看；对“最不可预测”且你不想再看的股票可手动淘汰，对被误杀的可加白名单。

## 11. 可视化看板（前端页面）

涨跌颜色遵循 A 股习惯（涨红跌绿），配置项 `color_scheme` 可切换。所有页面顶部显示统一筛选条与告警条。

### 11.1 总览 /ga/overview

- 筛选：周期（1 / 3 / 5 / 10 / 15 或全部）、日期范围、板块（00 / 60 / 30 / 全部）、口径（普通 / 严格 is\_effective）、数据范围（仅实盘 / 含回放）。
- KPI 卡片：整体命中率、看涨命中率、看跌命中率、覆盖率、平均 IC、已验证样本数、当前冠军版本与生效日、淘汰池股票数。
- 图表：（1）滚动 20 日命中率折线，5 个周期 5 条线，0.5 处画基准虚线；（2）按月命中率柱状图；（3）命中率日历热力图（高于 0.55 为绿，低于 0.45 为红，无样本为灰），点击某天跳转到“预测复盘”并带上日期。
- 使用方法：每天先看告警条与 KPI；折线持续低于 0.5 说明模型退化，去“进化监控”确认是否已自动触发进化。

### 11.2 预测复盘 /ga/predictions

- 表格列：基准日、代码、周期、预测方向（看涨 / 看跌 / 观望）、概率、置信度、到期日、实际收益、结果（正确 / 错误 / 待验证 / 作废，用图标与颜色区分）、涨跌停标记、冠军版本。
- 筛选：日期、周期、方向、结果（全部 / 正确 / 错误 / 待验证）、板块、置信度区间、是否在池。排序：实际收益绝对值、置信度。分页，支持导出 CSV。顶部摘要显示当前筛选下的命中率与样本数。
- 行点击进入个股详情。
- 使用方法：筛选“错误 + 置信度 ≥ 0.3”回看高置信错误；筛选“正确”观察成功样本的共性。

### 11.3 个股详情 /ga/stock/:market/:code

- K 线图（ECharts 蜡烛图 + 成交量），在基准日位置标记预测：向上三角表示看涨、向下三角表示看跌；已验证的角标带对勾（正确）或叉（错误）；悬浮提示周期、概率、实际收益；支持切换周期。
- 右侧面板：最新 5 个周期预测卡片（方向、概率、置信度、explain 贡献条形图）；该股分周期历史命中率表；淘汰状态时间线（来自 ga\_stock\_elimination\_log）。
- 使用方法：查看模型对某只股票的历史表现，决定是否信任其当前预测。

### 11.4 错误分析 /ga/analysis

五个标签页：分桶命中率（维度下拉选择，柱状图 + 样本数折线，样本小于 30 的桶置灰）；可靠性曲线与 ECE；混淆矩阵；高置信错误 Top 20；分层回测。

### 11.5 淘汰管理 /ga/pool

- 列表：当前淘汰股票（代码、原因码、原因说明、淘汰日期、60 日命中率、影子命中率、冷却剩余天数），可按原因码筛选；原因分布饼图；事件日志时间线（可按股票、日期过滤）；可预测性排行（10.10）。
- 操作：手动淘汰、手动复活、加入白名单（必须填写备注），操作写入日志。

### 11.6 进化监控 /ga/evolution

- 运行列表（周期、类型、数据截止日、代数、最优适应度、状态、告警信息）；选中一次运行后显示收敛曲线（best / avg / worst 适应度）、多样性曲线、每代淘汰数、名人堂表（各项指标）、基因可视化（只显示启用特征的权重条形图，正负不同颜色）。
- 冠军版本列表与两版对比、衰减曲线（10.7）。
- 按钮：手动触发进化（选周期）、触发回放（日期范围与步长）、晋升候选、回滚版本。

### 11.7 因子体检 /ga/factors

热力图（特征 × 周期，颜色表示 ic\_60，衰减预警带红框）；点击某个因子显示其 ic\_20、ic\_60 的时间序列。

### 11.8 每日选股榜 /ga/picks

按 10.5 的规则展示看涨榜与看跌榜，支持切换日期、Top N、周期共振数下限。

## 13. 定时任务

| 任务 | 触发时间 | 内容 |
| --- | --- | --- |
| FeatureJob | 每个交易日 17:30，或行情入库完成后 | 计算 stock\_feature\_daily 与 ga\_market\_daily |
| PredictJob | FeatureJob 之后 | 见 9.1 |
| VerifyJob | PredictJob 之后 | 见 9.2 |
| MetricJob + PoolJob | VerifyJob 之后 | MetricJob 见 9.3；PoolJob 每日评估 SUSPENDED、ST、NEW\_LISTING、LOW\_LIQUIDITY、DATA\_MISSING，每周日评估 POOR\_PREDICTABILITY、EXTREME\_VOL，并处理复活 |
| EvolveJob | 每周六 02:00，也可手动或告警触发 | 5 个周期依次进化，随后重拟 Platt 校准、更新因子体检、处理候选准入与影子晋升 |

通用要求：任务幂等、可重复执行；用互斥锁防止同一任务并发运行；记录开始与结束时间、耗时、处理条数；某个任务失败不阻塞后续无依赖任务，但要记录并告警；非交易日（stock\_daily 当日无数据）自动跳过。

## 14. 非功能需求与工程要求

- 性能目标：PredictJob（5 个周期，全池）小于 5 分钟；FeatureJob 小于 10 分钟；单周期 EvolveJob（pop\_size 200、max\_gen 60）在 8 核 / 16GB 内存的机器上小于 30 分钟；看板接口 P95 小于 1 秒（依赖 ga\_metric\_daily 与索引）。
- 内存：样本矩阵使用 float 数组，估算 `sample_per_day × 有标签日数 × N × 4 字节`（例如 600 × 200 × 50 × 4 ≈ 24MB）；适应度评估按个体并行。
- 可复现：每次运行保存 random\_seed、参数、特征顺序；同样数据与同样种子必须得到完全一致的结果（每个个体使用独立派生的随机数种子）。
- 数据质检：每日特征计算后检查价格口径（第 0 节）、关键字段缺失率、主键重复，异常写日志并在看板提示。
- 安全：看板与接口沿用项目现有登录鉴权；手动干预类接口记录操作人。
- 可配置：所有阈值走 ga\_config，修改后下一次任务生效，无需重启。
- 代码结构建议：engine（Individual、Population、选择 / 交叉 / 变异算子、GAEngine）、fitness（FoldSplitter、FitnessEvaluator）、feature（FeatureCalculator、Normalizer）、label（LabelBuilder）、predict（Ensembler、Calibrator）、verify（VerifyService）、pool（PoolEvaluator）、metric、job、api。

## 15. 验收标准与里程碑

### 15.1 验收用例（必须全部自动化测试）

1. 防未来函数：对任意日期 d，删除 d 之后所有 stock\_daily 行再计算 d 日特征，结果与原值逐位一致。
2. 标签与到期日：构造含停牌的序列，到期日跳过停牌日；不足 h 个交易日保持 PENDING，超 30 个自然日置 VOID。
3. GA 算子：BLX-α 结果在基因范围内；变异后 m 至少 3 位为 1；精英个体不被改动；同种子两次运行结果完全一致。
4. 适应度：用构造数据验证——特征与标签完全相关时 BalAcc 接近 1，随机特征时 BalAcc 接近 0.5 且 F 接近 0，覆盖率不足时惩罚生效。
5. 数据切分：训练段与验证段之间恰好隔 h 个交易日；Hold-out 样本不出现在任何折里。
6. 回填：重复执行结果不变；is\_correct 覆盖涨、跌、观望与收益恰为 0 的情形。
7. 股票淘汰：构造命中率 0.4、样本 50 的股票会被淘汰并写日志；满足复活条件后复活并写日志；冷却期内不重复动作。
8. 冠军准入：Hold-out 不达标的候选不得晋升；回滚后 ga\_champion\_set 每个周期只有一个 is\_current = 1 的版本。
9. 回放：回放预测只使用不晚于断点日的数据（检查 ga\_run.as\_of\_date 与所用数据最大日期）。
10. 接口：每个接口有契约测试，覆盖分页、空数据与非法参数。
